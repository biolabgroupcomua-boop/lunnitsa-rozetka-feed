## Що Pricecreator бере з фіду
- **Лише при першому імпорті:** назву, опис, бренд і категорію товару (довідка p371). Якщо їх змінено у фіді, повторний імпорт нічого не змінить. Щоб змінити: видалити категорії Лунниці разом із товарами → «Керування товарами» → «Кошик» → «Очистити все» (і «Показати категорії» → «Очистити все») → імпорт за посиланням → кроки нижче. Так можна лише доки товари не на Розетці, інакше це зняття з продажу.
- **При кожному імпорті:** характеристики (з'являються в «Характеристиках продавця»).
- **Щогодини (автооновлення):** ціну, наявність, кількість.
- **Фото:** лише з галочкою «оновити зображення» під час імпорту.

## Категорії й характеристики
- Категорії фіду — це кінцеві категорії Розетки (`categories.json`, id = `rz_id` = номер з адреси на rozetka.com.ua). Тому вони прив'язуються самі.
- Pricecreator переносить характеристику в поля Розетки лише за **точною назвою з налаштувань категорії в кабінеті** (`pricecreator_params.json`), а не за назвою фільтра на сайті. Наприклад, «Країна-виробник товару», а не «Країна-виробник»; «Категорія», а не «Стать»; «Галузь застосування», а не «Сфера застосування». У товарі має бути щонайменше 2 такі характеристики (у XML), на Розетці 3.
- Рішення Olena 20.10: усе «Для жінок», «Клас косметики» — Натуральна. Парфуми — «Нішева» (так на упаковці).

## Після змін у фіді (новий товар, нова категорія, нові характеристики)
```
set PC_LOGIN=...  &  set PC_PASSWORD=...        (пароль у файли не записувати)
python tools/pricecreator.py import             # імпорт нашого фіду
python tools/pricecreator.py setup              # поля Розетки в категоріях Лунниці + «Оновити зв'язки»
python tools/pricecreator.py compare            # «Порівняння» параметрів (до 2 хв на категорію)
python tools/pricecreator.py xml                # що буде перенесено в XML; потім те саме з --go
python tools/pricecreator.py check              # помилки, у XML, автооновлення, останнє звернення Розетки
```
Новий товар спершу дописати в `categories.json` (інакше він лишиться в категорії Horoshop і буде в `status.json` → `no_category`).

## Що свідомо не ввімкнено
- «Вимкнути відсутні» в автооновленні: кабінет спільний з Melony, ризик зачепити її товари. Наш фід сам ставить `available="false"` товарам, яких немає в наявності.
- Ціна в автооновленні: «Системне налаштування», як у Melony.
